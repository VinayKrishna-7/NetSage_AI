# NetSage AI - Screenshots Directory

This directory stores visual captures and figures of the NetSage AI application for viva presentations, academic defense slides, and project documentation.

---

## Recommended Screenshots to Capture

1. **`01_home_page.png`**
   - Streamlit Home screen with KPI metrics cards, safety advisory banner, and system architecture.

2. **`02_case_dataset_filter.png`**
   - Dataset explorer filtering cases by fault domain (VLAN, Gateway, DHCP, Routing, ACL, NAT, etc.).

3. **`03_troubleshoot_case_details.png`**
   - The interactive workbench showing symptom, topology, client IP configuration, and Cisco show output for Case `NET005` or `NET001`.

4. **`04_rule_checker_evaluation.png`**
   - Deterministic rule checker flagging a failure (e.g. `gateway_mismatch` or `interface_status: administratively down`).

5. **`05_ai_diagnosis_structured.png`**
   - Structured AI advisory card showing Root Cause, Confidence, OSI Layer, cited evidence lines, and Cisco fix commands.

6. **`06_human_review_submission.png`**
   - Human-in-the-Loop review form showing selection of `ACCEPTED`, `EDITED`, or `REJECTED` with reviewer explanation.

7. **`07_responsible_ai_log.png`**
   - Responsible AI log showing documented cases where AI failed and lessons learned.

8. **`08_analytics_dashboard.png`**
   - Analytics dashboard displaying Plotly charts for fault domain breakdown, OSI layers, severity distribution, and human-AI agreement rate.

9. **`09_packet_tracer_topology.png`**
   - Cisco Packet Tracer screenshot demonstrating the topology, failed ping, and successful verification after fix.

---

## How to Add Screenshots
Place your PNG or JPEG files into this `screenshots/` directory. They can then be referenced in Markdown reports or presentation slides.
